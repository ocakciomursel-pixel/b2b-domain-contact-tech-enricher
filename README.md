# WooCommerce Store Product Catalog, SKU & Pricing Extractor

> **WooCommerce Product Scraper | Store Catalog, Prices & Stock Status** — E-commerce competitive intelligence: scans WooCommerce storefronts via public Store REST API and HTML product markup to extract product titles, prices, and URLs.

---

## Key Capabilities & Performance Advantages

- **Direct Structured Extraction**: Engineered with lightweight HTTP and structured API/DOM parsers—zero headless browser overhead and ultra-fast cloud execution.
- **Pay-Per-Event Billing (`wc-product-extracted`)**: Transparent event-based pricing ($0.003 per record).
- **Automated Daily Reliability**: Built-in fallback defaults ensure 100% dataset stability for scheduled pipelines, Make, n8n, Zapier, Clay, and REST API workflows.
