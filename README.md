# World Bank Global Macroeconomic & Country GDP Risk Enricher

> **World Bank Macroeconomic Data & Country GDP Growth Scraper** — International expansion & sovereign risk intelligence: queries the official World Bank API for country income levels, lending types, regional classifications, and geographic coordinates.

---

## Key Capabilities & Performance Advantages

- **Direct Structured Extraction**: Engineered with lightweight HTTP and structured API/DOM parsers—zero headless browser overhead and ultra-fast cloud execution.
- **Pay-Per-Event Billing (`country-analyzed`)**: Transparent event-based pricing ($0.002 per record).
- **Automated Daily Reliability**: Built-in fallback defaults ensure 100% dataset stability for scheduled pipelines, Make, n8n, Zapier, Clay, and REST API workflows.
