## Quickstart: Model Context Protocol (MCP) for Claude Desktop, Cursor & Windsurf

Add any of the 29 Actors above to your `claude_desktop_config.json` or `.cursor/mcp.json` using the official `@apify/actors-mcp-server`:

```json
{
  "mcpServers": {
    "apify-b2b-intelligence": {
      "command": "npx",
      "args": [
        "-y",
        "@apify/actors-mcp-server",
        "--actors",
        "lucacelli/github-developer-recruiter-lead-enricher,lucacelli/sec-edgar-company-10k-8k-filing-monitor,lucacelli/b2b-domain-contact-tech-enricher,lucacelli/clinical-trials-fda-drug-safety-intel,lucacelli/cve-vulnerability-nvd-exploit-monitor,lucacelli/google-maps-scraper-places-emails-contacts-reviews"
      ],
      "env": {
        "APIFY_TOKEN": "YOUR_APIFY_API_TOKEN"
      }
    }
  }
}
```

## Quickstart: Python & Node.js SDK

### Python (`apify-client`)
```python
from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_API_TOKEN")

# Example 1: GitHub Developer & Recruiter Lead Enricher
run = client.actor("lucacelli/github-developer-recruiter-lead-enricher").call(run_input={
    "repositories": ["langchain-ai/langchain", "n8n-io/n8n"],
    "maxContributors": 25
})
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)
```

### Node.js / TypeScript (`apify-client`)
```javascript
import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: process.env.APIFY_TOKEN });

// Example 2: SEC EDGAR 10-K / 8-K Filing Monitor
const run = await client.actor('lucacelli/sec-edgar-company-10k-8k-filing-monitor').call({
  tickers: ['AAPL', 'NVDA', 'MSFT']
});
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);
```
