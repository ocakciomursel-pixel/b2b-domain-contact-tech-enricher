# Technical SEO, Broken Link, Schema.org & Meta Tag Auditor (MCP Ready)

Run a comprehensive 40-point technical SEO & AI-readiness audit across any list of URLs and receive an instant **0–100 SEO Health Score** with prioritized engineering fixes.

## Checks Performed
- **Core Meta & Indexing**: `<title>` length, `meta[name="description"]` length, `<link rel="canonical">`, `meta[name="robots"]` (`noindex` detection), and mobile viewport configuration.
- **Heading & Accessibility Structure**: `H1` count & text extraction, total images vs. missing `alt` attributes.
- **Structured Data & Social Cards**: Validates `application/ld+json` (`Schema.org`) blocks and OpenGraph tags.
- **Live Broken Link Verification**: Tests page links for `4xx`/`5xx` dead endpoints.
