# Europe PMC Biomedical Literature, Preprint & Citation Miner

> **Europe PMC Scraper | Open-Access Medical Papers, bioRxiv & Citations** — Global life-science & clinical literature miner: queries EMBL-EBI Europe PMC for biomedical publications, preprints, citation metrics, and author metadata.

---

## Key Capabilities & Performance Advantages

- **Direct Structured Extraction**: Engineered with lightweight HTTP and structured API/DOM parsers—zero headless browser overhead and ultra-fast cloud execution.
- **Pay-Per-Event Billing (`paper-extracted`)**: Transparent event-based pricing ($0.003 per record).
- **Automated Daily Reliability**: Built-in fallback defaults ensure 100% dataset stability for scheduled pipelines, Make, n8n, Zapier, Clay, and REST API workflows.
