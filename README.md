# Substack Newsletter Archive, Author & Content Velocity Scraper

> **Substack Newsletter Scraper | Posts, Authors & Publishing Frequency** — Newsletter sponsorship & media PR intelligence: extracts recent posts, author names, publishing dates, and links from Substack publications.

---

## Key Capabilities & Performance Advantages

- **Direct Structured Extraction**: Engineered with lightweight HTTP and structured API/DOM parsers—zero headless browser overhead and ultra-fast cloud execution.
- **Pay-Per-Event Billing (`newsletter-post-extracted`)**: Transparent event-based pricing ($0.003 per record).
- **Automated Daily Reliability**: Built-in fallback defaults ensure 100% dataset stability for scheduled pipelines, Make, n8n, Zapier, Clay, and REST API workflows.
