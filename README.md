# AI & LLM Website to Clean Markdown, Chunks & Metadata (MCP Ready)

Turn any website or documentation URL into clean LLM-ready Markdown, overlapping RAG text chunks with token estimates, and structured `JSON-LD` metadata.

## Why AI Developers & MCP Agents Use This Actor
- **Clean Markdown Extraction**: Strips noisy navigation bars, ads, scripts, and footers while preserving headings, lists, tables, and code blocks.
- **Built-in Overlapping RAG Chunker**: Automatically splits page content into configurable character chunks with context overlap and estimated token counts (`estimatedTokens`).
- **Optional Same-Domain Subpage Crawling**: Crawl an entire documentation section from a single start URL.
