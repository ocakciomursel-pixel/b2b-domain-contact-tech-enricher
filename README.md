# CPG Grocery Product Barcode (EAN/UPC), Brand & Ingredient Spy

> **OpenFoodFacts CPG Grocery Scraper | Barcode, Brand & Nutri-Score Data** — Retail & CPG supply-chain intelligence: extracts food & beverage product barcodes, brand manufacturers, nutrition scores, allergens, and ingredient lists.

---

## Key Capabilities & Performance Advantages

- **Direct Structured Extraction**: Engineered with lightweight HTTP and structured API/DOM parsers—zero headless browser overhead and ultra-fast cloud execution.
- **Pay-Per-Event Billing (`product-enriched`)**: Transparent event-based pricing ($0.002 per record).
- **Automated Daily Reliability**: Built-in fallback defaults ensure 100% dataset stability for scheduled pipelines, Make, n8n, Zapier, Clay, and REST API workflows.
