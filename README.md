# IANA Root Zone TLD Registry, Sponsor & NIC Operator Directory

> **IANA TLD Registry Scraper | Domain Registries & RDAP Servers** — Domain industry & cybersecurity infrastructure tool: maps top-level domains (gTLDs and ccTLDs) to their authoritative RDAP registry endpoints.

---

## Key Capabilities & Performance Advantages

- **Direct Structured Extraction**: Engineered with high-speed HTTP and structured API/DOM parsers—zero headless browser overhead and minimal compute cost.
- **Pay-Per-Event Billing (`tld-registry-extracted`)**: Transparent event-based pricing ($0.002 per record).
- **Automated Daily Reliability**: Built-in fallback defaults ensure 100% dataset stability for scheduled pipelines, Make, n8n, Zapier, Clay, and REST API workflows.
