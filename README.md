# Shopify Store Product, Pricing & Contact Intelligence (MCP Ready)

Extract structured product catalogs, variant pricing, stock availability, sale discounts, and merchant contact/social media profiles from any Shopify store without slow headless browsers.

## Features
- **Complete Catalog & Variant Data**: Extracts product titles, handles, URLs, SKUs, variant prices, compare-at prices (`onSale` detection), and live stock availability.
- **Merchant Contact & Social Enrichment**: Automatically scans the storefront for contact emails, currency code, and social profiles (Instagram, TikTok, Facebook, X/Twitter, YouTube, LinkedIn).
- **Zero Headless Browser Overhead**: Uses lightweight HTTP requests for ultra-low Apify compute cost and fast response times.
- **MCP & Automation Ready**: Ideal for e-commerce competitive research, dropshipping product discovery, B2B agency prospecting, and AI agent workflows.
