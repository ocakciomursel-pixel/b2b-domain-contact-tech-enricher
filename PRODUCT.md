# PRODUCT.md - Lucacelli Cloud Intelligence

## Product Truth
Lucacelli Cloud Intelligence (`@lucacelli` on Apify Store) provides 14 live public pay-per-event web extraction and B2B intelligence APIs, paired with an installable Hybrid WordPress Plugin (v2.0), Chrome Extension (v3.0), and Google Sheets Custom Formula Add-on (`=LUCACELLI_ENRICH`).

## Target Audience
- Growth engineers, B2B outbound agencies, technical SEO consultants, and AI/RAG builders.
- Users who want zero-maintenance JSON/CSV extraction using Apify's renewable $5.00/month free cloud credit (3,333 to 10,000 records/month free) with transparent single-event pricing ($0.50 to $1.50 per 1,000 items).

## Core Surfaces & Modes
- **Landing & Product Hub (`index.html`, `sheets-addon.html`, `automations.html`):** Mode `Persuade` + embedded `data-ui` live API workbench.
- **Interactive Plugin & Cloud Workbench (`plugin-demo.html`):** Mode `Operate` (App Screen style `data-terminal`).
- **Catalog & OpenAPI Reference (`catalog-200.html`, `api-docs.html`):** Mode `Read` / `Operate`.
